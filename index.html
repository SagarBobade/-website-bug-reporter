## 🐛 Bug Report: Login Button Unresponsive on Mobile

**Priority:** High | **Component:** Authentication | **Environment:** Chrome Mobile

### Summary
Login button becomes unresponsive after username input on mobile devices, preventing user authentication.

### Steps to Reproduce
1. Navigate to login page on mobile device
2. Enter valid username in username field
3. Attempt to click "Login" button
4. Observe button does not respond to touch events

### Expected Result
Login button should be clickable and initiate authentication process

### Actual Result
Button appears enabled but does not respond to touch events, no visual feedback

### Environment
- **Browser:** Chrome 119.0 (Mobile)
- **Device:** iPhone 13 Pro
- **Screen:** 390x844 resolution
- **OS:** iOS 17.1

### Screenshots
📷 2 screenshots attached showing button state before/after interaction

### Additional Context
Issue only occurs on touch devices, desktop mouse clicks work normally
Suspected CSS touch-action or z-index layering issue

How It Works

Natural workflow that feels effortless

1

Speak About What's Broken

Just describe the issue naturally. Voice recording captures your explanation while you navigate the problem. No need to write anything yet.

2

Add Screenshot, Video If Necessary

Press Ctrl+Shift+S for screenshots or start screen recording for complex flows. Annotate with arrows and highlights to show exactly what's wrong.

3

Ask AI to Write

Hit the generate button and watch AI transform your voice notes and screenshots into a professional bug report with proper formatting and clear steps.

4

Share Anywhere

Copy the perfectly formatted report and paste directly into Jira, GitHub, Slack, or any platform. Videos and screenshots export separately if needed.

Easy Installation

Get started in minutes with our step-by-step guide

1

Install BugReporter Extension

Download from Chrome Web Store and pin to your toolbar for quick access

2

Choose Your AI Provider

Select from Gemini, OpenAI, Anthropic, or xAI based on your preference and existing accounts

3

Set Up OAuth Authentication

Add your AI model API key in the settings panel

4

Start Capturing Bugs!

Click the extension icon or use your keyboard shortcut to capture your first bug report

Frequently Asked Questions

Get answers to common questions about BugReporter

For Gemini, you can use OAuth authentication (no API key needed). For OpenAI, Anthropic, and xAI, you'll need your own API key. You can still capture and annotate screenshots without any AI setup - the AI is only needed for automatic report generation.
All data is processed locally in your browser and only sent to your chosen AI provider for report generation. Screenshots and recordings are stored locally and never shared with third parties. API keys are stored securely in Chrome's storage.
Bug reports are generated in Markdown format, perfect for Jira, GitHub, Linear, and most tracking systems. You can copy as HTML or plain text. Videos are exported as WebM files, and screenshots as PNG images.
Default shortcuts: Ctrl+Shift+S for instant screenshot capture, Ctrl+Shift+M for microphone toggle. You can customize these in chrome://extensions/shortcuts to fit your workflow.
Yes! You can edit the generated report directly, regenerate with updated inputs, or use the chat feature to iteratively improve the report with AI assistance. All changes are saved automatically.
Screen recording works on most websites, but is blocked on Chrome internal pages (chrome:// URLs) for security reasons. You'll be notified if recording isn't available on a specific page.
